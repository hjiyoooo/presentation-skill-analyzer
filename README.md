# presentation-skill-analyzer

# 한국어 발표 스킬 자동 분석 시스템

## 프로젝트 개요
한국어 발표 음성을 받아 항목별 점수와 개선 피드백을 자동으로 생성하는 ML/DL 시스템

## 분석 항목
- 말 속도 (WPM)
- 필러워드 비율 ("음", "어", "그", 등)
- 침묵 패턴
- 억양 변화
- 어휘 다양성

## 데이터셋
- 한국어 강의 음성 (AI Hub - KlecSpeech)
- KsponSpeech (AI Hub)
- 한국인의 주제적응형 영어말하기 평가데이터 (AI Hub)
